# Void Ascension

A high-octane cyberpunk twin-stick shooter for Android, featuring fast-paced combat, deep upgrade systems, and a responsive neon-infused UI.

## 🚀 Key Features

### 🎮 Gameplay Mechanics
- **Twin-Stick Controls**: Intuitive dual virtual joysticks for precise movement and directional firing.
- **Dynamic Wave System**: Face increasingly difficult waves of cosmic horrors, culminating in challenging boss encounters.
- **Real-time Combat Engine**: A custom-built game engine utilizing `SurfaceView` for high-performance 2D rendering at 60 FPS.
- **Combat Systems**: Piercing projectiles, critical hits, area-of-effect explosions, homing shots, and diverse enemy AI.
- **Avatar System**: Choose from various bio-forms like `VOID CORE`, `NEBULA EYE`, `RIFT PRISM`, and more, each with unique visual styles and shapes.
- **Advanced Combat Features**:
    - **Twins**: Deploy orbital symbionts that fire alongside you.
    - **Entropy Shockwaves**: Rare screen-clearing events that destroy entire waves.
    - **Confusion**: Confuse enemies, making them lose track of your position.

### ⚡ Upgrade Systems
- **In-Game Upgrades (Adaptations)**: Choose between randomized mutations, weapons, and auras every time you clear a wave.
- **Permanent Progression**: Collect "Void Shards" during your runs to purchase permanent stat boosts and epic abilities like `Xenon Strike` or `The Ascension Protocol`.
- **Mutations & Auras**: Customize your build with passive effects like `Static Field`, `Plasma Shield`, `Void Drain`, and `Titan Slayer`.

### 📱 Advanced UI & UX
- **Interactive Tutorials**: Comprehensive step-by-step intro and in-game guides to help new pilots master the neural link.
- **Responsive Design**: All game UI and menus are built to adapt perfectly to any screen size and aspect ratio.
- **Orientation Support**: Seamlessly toggle between **Portrait** and **Landscape** modes in-game via a dedicated orientation button.
- **Consolidated HUD**: A clean dashboard provides real-time feedback on Health, XP, Level, Current Wave, Score, and Kill count.
- **Cyberpunk Aesthetic**: High-contrast neon visuals, monospace typography, and smooth animations.

### 🛠 Technical Details
- **Architecture**: Modern Android development with **Kotlin**, **Dagger Hilt** for Dependency Injection, and **ViewBinding**.
- **Performance**: Optimized rendering loop with custom particle systems and frame-rate independent physics.
- **Persistence**: Game state and permanent upgrades managed via a secure `SaveManager` with **Room Database** and **SharedPreferences**.

### 🔓 Cheat System

- `MAURAG_PO_AKO`: Max stats and all mutations/auras instantly.
- `AIKI`: Instant level up on every kill.
- `MOCHI_MOCHI`: Explosive chain reaction on enemy death.

## 🕹 How to Play
1. **Move**: Use the left joystick to navigate the void.
2. **Shoot**: Use the right joystick to aim and fire, or let the auto-aim assist you.
3. **Ascend**: Collect XP shards and health packs from fallen enemies.
4. **Upgrade**: Select powerful augmentations after each wave to build your ultimate cosmic survivor.
5. **Survive**: Defeat the Titans and ascend beyond the void!
